# Programming Fundamentals

Exercises and examples from programming fundamentals, written in Java.
Each file is a standalone program with its own `main`.

## Folders

| Folder | Topic |
|---|---|
| `algorithm_exercises` | Sequential algorithms: coins, money, remainder, salary, seconds, telephone operator |
| `maths` | Operators, even/odd, positive/negative, exponential |
| `conditionals` | if / else if / switch: largest of three, leap year, triangle type, quadratic equation, calculator, BMI |
| `repetitive_structures` | Patterns with nested loops: square, rectangle, triangles |
| `loops` | while / do-while / for: factorial, Fibonacci, primes, palindromes, GCD, statistics |
| `arrays` | One-dimensional arrays: statistics, reverse, duplicates, merge, rotate |
| `matrices` | Two-dimensional arrays: sum, transpose, multiplication, spiral, magic square |
| `strings` | Text handling: vowels, palindromes, Caesar cipher, anagrams, password validation |
| `methods_and_recursion` | Methods and recursive solutions: factorial, Fibonacci, power, Hanoi, binary |
| `searching_and_sorting` | Linear/binary search and bubble, selection, insertion, merge, quick sort |
| `classes_and_objects` | Classes, encapsulation, inheritance, polymorphism, ArrayList |

## Run

```bash
cd loops
javac Factorial.java
java Factorial
```
